```
   ┌────────────────────┐    ┌─────────────────┐    ┌──────────────────┐
   │ AI vendor's model  │ →  │ Mneme antivirus │ →  │ vendor PAYS      │
   │ hallucinates a SHA │    │ catches + logs  │    │ $0.01 per block  │
   └────────────────────┘    └─────────────────┘    └──────────────────┘
```

The vendor *wants* to pay because Mneme makes their model look more
trustworthy. Aligned incentives. No blame, just reduced refund rate.
