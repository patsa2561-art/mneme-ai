## House rules

1. **No paid stars, no engagement farms.** GitHub bans these and the dev community detects them quickly.
2. **Lead with the demo, not the pitch.** A 30-second GIF is worth a thousand-word blog post.
3. **Honest numbers only.** Quote `recall@3 ≈ 87%`, `244 tests`, `50-question eval set`, `8 essential CLI commands` — not "industry-leading retrieval." Devs verify.
4. **Reply within the first 4 hours.** That's when the algorithms decide whether to keep showing the post.
5. **Show HN is one shot.** A failed Show HN is hard to retry. Post when *everything* is ready — not when you're impatient.
