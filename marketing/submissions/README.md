## How GitHub PR works (3-step pattern)

Every awesome-list PR follows the exact same 3 steps:

### Step 1 — Click the fork link
GitHub will say "Create a fork" — click → wait 5 seconds → it redirects to your fork.

### Step 2 — Edit the file in browser
- Click the file name (usually `README.md`)
- Click pencil icon ✏️ at top right
- Use `Ctrl+F` to find the right section
- Paste the prepared one-line entry (alphabetical position)
- Scroll down to **"Commit changes"**
- Use the prepared commit message
- Select **"Create a new branch"** (don't commit to main)
- Click **"Propose changes"**

### Step 3 — Open the Pull Request
- GitHub redirects to "Comparing changes" page
- Click **"Create pull request"**
- Paste prepared title + body
- Click **"Create pull request"** again (final confirm)

That's it. PR is open. Maintainer review takes 1-7 days.
