## 🧠 Currently Building

### [Mneme](https://github.com/patsa2561-art/mneme-ai) — memory layer for AI coding assistants

> Your codebase has memory. Your AI assistant has 0. I'm fixing that.

**What it does:** Indexes your git history + code structure into a local SQLite database, exposes it via MCP so AI coding assistants can finally answer *"why is this code structured this way?"* with real context instead of guesses.

**Stack:** TypeScript · SQLite + FTS5 · Hybrid retrieval (BM25 + cosine + RRF) · MCP server · Property-based testing

**Philosophy:** local-first · no telemetry · works offline with Ollama · MIT licensed

```bash
npx mneme-ai init
npx mneme-ai ask "what does this project do"
```

## 🐍 Snake Animation Setup (สำคัญ!)

Snake animation ต้องตั้ง GitHub Action เพิ่ม ไม่งั้นจะแสดงเป็น **broken image**

### Step 1: ใน repo `patsa2561-art/patsa2561-art`

สร้างไฟล์: `.github/workflows/snake.yml`

### Step 2: paste content นี้

```yaml
name: Generate Snake

on:
  schedule:
    - cron: "0 */24 * * *"
  workflow_dispatch:
  push:
    branches:
      - main

jobs:
  generate:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - name: Generate snake
        uses: Platane/snk/svg-only@v3
        with:
          github_user_name: patsa2561-art
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark

      - name: Push to output branch
        uses: crazy-max/ghaction-github-pages@v3.1.0
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

### Step 3: Run workflow

1. ไปที่ tab **Actions** ของ repo
2. คลิก **"Generate Snake"** workflow
3. กด **"Run workflow"** → Run

รอ 30 วินาที → snake จะ generate มาที่ branch `output` → README จะแสดง animation
